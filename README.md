# TrustFile

Free online file converter and PDF tools — 100% client-side. Files never leave the user's device.

Live site: https://trustfile-sigma.vercel.app/

## Tools (23)
PDF tools: Merge, Split, Compress, Rotate, Delete Pages, Add Page Numbers, Add Watermark.
Convert from PDF: PDF to Word, JPG, PNG, Text, Excel.
Convert to PDF: Word, Excel, JPG, TXT, CSV, HTML to PDF.
Images & documents: PNG to JPG, Image Converter, TXT to Word, Word to Text, Excel to CSV.

## Structure
- `index.html` — homepage + searchable tool grid
- `<tool>.html` — one SEO landing page per tool (unique titles, descriptions, canonicals, JSON-LD)
- `css/style.css` — design system
- `js/engine.js` — conversion engine (pdf-lib, pdf.js, mammoth, SheetJS, JSZip, jsPDF, html2canvas — lazy-loaded from CDN with fallbacks)
- `js/tool-ui.js` — tool workspace UI (dropzone, file list, options, progress, results/ZIP)
- `js/main.js` — header nav, footer year, homepage search
- `sitemap.xml`, `robots.txt` — SEO

Pages are generated by `../trustfile-build/build_site.py` (kept outside this repo).

## Honest limits
PDF to Word/Excel extracts text (exact layout not preserved). Scanned (image-only) PDFs are read automatically with built-in OCR (Tesseract.js); clear scans work best, handwriting and blurry scans may not read well. Compress PDF re-renders pages as images, so text is no longer selectable. PPTX to PDF and PDF to PowerPoint need a server and are not offered.

## Deploy
Vercel serves this repo from the `main` branch (auto-deploys on every push). No build step.
